Важные границы результата:

- Scamalytics прямо сообщает, что не имеет видимости трафика самого адреса; оценка 0 основана на видимых данных сети оператора. Это не доказательство отсутствия истории злоупотреблений.

- Datacenter Unknown — неопределённость, а не подтверждение домашнего подключения. Название Hosting RS само по себе не определяет тип линии. Residential Proxy No означает отсутствие такой отметки в базе, а не опровержение продукта ISP.
- 215 ms — результат веб-тестера провайдера, не замер задержки от пользовательского ПК до прокси.
- Доступность Claude, стабильность с ПК, DNS, ожидаемый egress и fail-closed ещё не проверены. Gate 4 не пройден.
- Репутационная часть этапа 3 выполнена. Gate 3 требует явного принятия IP пользователем; в журнале пока не закрыт.
- Смена показанного в чате пароля рекомендована, но её выполнение не подтверждено. Реквизиты не копировать в документацию, команды, Git и новые скриншоты.

## Как повторить проверку

### 1. Проверить заказ и скопировать строку SOCKS5

1. Открыть [кабинет IPRoyal](https://dashboard.iproyal.com/).
2. В левом меню выбрать Proxies → ISP. В таблице нажать номер нужного заказа в столбце Order ID. Альтернативно открыть My Orders и выбрать нужный заказ.
3. На вкладке Order details сверить страну, Dedicated, количество IP, срок, IP quality (Scamalytics), стоимость и Subscription. Записать точное время окончания, если оно доступно.
4. Открыть Proxy details. Над или под таблицей подключения найти Protocol / Port / Format; расположение может отличаться между страницами кабинета.
5. Выбрать SOCKS5. Для проверенного заказа порт — 12324; для нового заказа брать порт из кабинета, а не угадывать.
6. Выбрать формат HOST:PORT:USER:PASS и нажать Copy list под таблицей. В общем списке аналогичная кнопка называется Copy proxies.
7. Полную строку вставлять только в локальную конфигурацию или официальный тестер IPRoyal. Не присылать её в чат и не сохранять в репозиторий.

### 2. Запустить Proxy Tester IPRoyal

1. Внутри заказа Proxy details найти блок Test your proxy list под полями Protocol / Port / Format и нажать Test now. Если блока нет, открыть меню Tools и найти Proxy Tester; при изменении интерфейса ориентироваться по фактическому экрану.
2. На странице Proxy Tester справа сверху выбрать Select protocol → SOCKS5.
3. Рядом в Select proxy format выбрать HOST:PORT:USER:PASS.
4. В большое поле справа Enter proxy list, one proxy per line вставить скопированную строку через Ctrl+V.
5. Слева нажать Begin test; при повторной проверке кнопка называется Start new test.
6. В нижней таблице проверить Type=SOCKS5, Status=OK, код ответа, страну и время ответа. Для отчёта сохранять только нижнюю таблицу, скрывая полный IP при публикации.
7. Windows-приложение тестера для этой проверки не требуется.

Первый тест в этой сессии дал FAIL: тестер был оставлен в HTTP/HTTPS при SOCKS5-порте 12324. После изменения только Select protocol на SOCKS5 тест дал OK / 200. Такой FAIL сам по себе не означает неисправный IP.

### 3. Проверить Scamalytics

1. Вверху браузера нажать «+» справа от вкладок. В адресную строку новой вкладки вставить `https://scamalytics.com/ip` и нажать Enter. Это отдельный сайт, не кнопка в IPRoyal.
2. В поле поиска IP в верхней части страницы вставить только адрес из столбца IP, без порта, логина и пароля. Нажать кнопку с лупой справа.
3. В блоке Fraud Risk записать Fraud Score и уровень риска. Для Premium / Scamalytics ожидается 0 на момент выдачи; расхождения фиксировать и обсуждать с поддержкой.
4. Прочитать пояснение под шкалой: оценка может основываться на сети, если данных о самом IP нет.
5. Прокрутить вниз до Operator, Location, Datacenter, External Blacklists, Proxies и Residential Proxy. Зафиксировать ASN, ISP, organization, страну/город, флаги и списки. Unknown не превращать в No.

### 4. Проверить AbuseIPDB независимо

1. Открыть новую вкладку и перейти на `https://www.abuseipdb.com/`.
2. В поле Check an IP Address вверху страницы вставить только IP и нажать Check.
3. Записать Abuse Confidence Score, количество/давность жалоб, Usage Type, ISP, ASN и геолокацию.
4. Если показано Not found in database / No reports, записать именно отсутствие жалоб, не объявлять IP гарантированно безопасным.
5. Не нажимать Report: мы проверяем адрес, а не отправляем жалобу.

### 5. Проверить соединение до больших загрузок

После принятия IP пользователем настроить SOCKS5 в Cage локально. Проверить фактический внешний IP, DNS, несколько подключений и поведение при отказе прокси по этапу 4 PLAN.md. Авторизацию Claude выполнять только после сетевых проверок. При отказе сервиса зафиксировать ошибку для диагностики.

До решения о пригодности удерживать трафик ниже 500 МБ. Не начинать большие загрузки Linux/tooling через тестируемый прокси, пока не закончены проверки и не принято решение о сохранении заказа.

## Продление, замена и возврат

Ответ поддержки, предоставленный пользователем:

- Наличие claude.ai и api.anthropic.com вне списка ограничений провайдера не гарантирует доступ: конечный сервис может отклонить IP.
- Одна замена в первые 24 часа, общий трафик не более 500 МБ; Extra Requirements обрабатываются вручную.
- Zero-risk связан с одной выбранной системой; оценки других баз не покрываются, показатели могут меняться.
- Неразрешённые поддержкой проблемы подключения могут дать право на возврат; автоматического обещания возврата нет.
- Продление до окончания срока сохраняет IP; после истечения адрес возвращается в пул и не резервируется.

Перед обращением повторно прочитать актуальные условия: формулировки лимитов и исключения могут меняться. Запросить помощь сразу при проблеме, не ждать истечения суток. Автопродление суточной подписки обычно добавляет ещё сутки; для месяца выбрать нужный срок вручную в Extend активного заказа. Не создавать новый заказ вместо продления, если важно сохранить IP.

## Что показала проверка отзывов

На 2026-11-12 у [Trustpilot](https://www.trustpilot.com/review/iproyal.com) было предупреждение: рейтинг недоступен из-за нарушения правил, часть поддельных отзывов удалена. Есть как положительные отзывы о поддержке, так и жалобы на задержки, геолокацию и возвраты. Это пользовательские сообщения, не статистика неисправностей нашего IP.

[Proxyway ISP 2026](https://proxyway.com/research/isp-proxies-2026) публикует тесты других географий; они не доказывают качество польского или эстонского пула и не проверяют Claude. У сайта партнёрские ссылки, тестовые образцы могли отличаться от self-service. Поэтому решение опирается на проверки выданного адреса и реального маршрута, а не общий рейтинг продавца.
