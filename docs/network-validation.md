# Проверка отказа IPRoyal — 2026-11-13

## Результат

При временной блокировке адреса единственного прокси IPRoyal проверенные запросы из Linux Cage не получили HTTP-ответ. После снятия блокировки доступ восстановился с тем же внешним IP. Прямой выход в проверенных запросах не обнаружен.

## Метод и наблюдения

- Cage 0.1.7, Debian 13; CLI `cage run` выполнял запросы внутри guest.
- До теста HTTPS-запрос к api.ipify.org прошёл. IP сравнивался по SHA256 без записи полного адреса в документацию.
- Через UAC добавлено временное исходящее Windows Firewall правило только для единственного адреса `server` из текущей конфигурации Mihomo. Интернет Windows целиком не отключался; настройки/credentials прокси не менялись.
- Правило имело автоматическое удаление через 100 секунд и было удалено сразу после тестовых запросов через сигнал завершения и `finally`.
- Во время блокировки: api.ipify.org — curl 35, TLS EOF, HTTP 000; example.com — curl 28, DNS timeout, HTTP 000.
- Дополнительный запрос `curl --noproxy "*" http://1.1.1.1` — curl 52, empty reply, HTTP 000. Это проверка попытки обхода proxy-переменных в curl; само по себе сообщение empty reply не показывает место блокировки.
- После удаления правила api.ipify.org снова доступен; хеш IP совпадает с исходным.
- В proxy.status до, во время и после теста оставался тот же единственный SOCKS5 узел/маршрут IPRoyal. Статус во время короткой блокировки оставался `ready`, `network_open=true`; это не доказательство доступности внешней сети. IPv6/UDP отмечены как заблокированные, отдельно пакетами не проверялись.

## Ограничения

Это реальная кратковременная блокировка upstream-адреса прокси на хосте, а не встроенная диагностическая fault injection и не остановка всей VM. Проверены конкретные запросы Linux guest. Browser и Claude Desktop отдельно в этом тесте не проверялись: управление UI недоступно (`native pipe unavailable`). Захват пакетов, длительный отказ, перезапуск Cage при отказе и повторный старт Windows не проверялись. Gate 4 целиком не закрывается этим ограниченным тестом.

Постоянные сетевые настройки не изменялись. Временное правило удалено; доступ Cage восстановлен.
