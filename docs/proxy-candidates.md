# Proxy candidates

## Зачем этот файл

Это shortlist провайдеров, который был предварительно обсуждён до начала практической настройки Claude Cage.

Это **не окончательный выбор** и не разрешение на покупку. Перед выбором необходимо заново проверить актуальные предложения и условия у самих провайдеров.

## Требования проекта к proxy

Ищем один proxy для постоянной работы среды Cage:

- dedicated / выделенный IP;
- static / постоянный IP без ротации;
- ISP proxy предпочтительнее обычного shared datacenter proxy;
- SOCKS5;
- возможность использовать proxy напрямую из текущего интернет-подключения без постоянно включённого системного VPN;
- стабильная география;
- приемлемая репутация IP на момент выдачи;
- понятные условия замены IP, если выданный адрес технически проблемный;
- credentials никогда не сохраняются в Git.

Важно отдельно проверять две вещи:

1. открывается ли сайт/личный кабинет провайдера без VPN;
2. доступен ли непосредственно SOCKS5 endpoint (host:port) без VPN.

Первое не доказывает второе.

## Предварительный shortlist

### 1. IPRoyal ISP — основной кандидат

Ранее рассматривался первым.

Что нужно перепроверить перед покупкой:

- наличие dedicated/static ISP proxy;
- SOCKS5;
- доступные страны/география;
- актуальная цена;
- является ли IP действительно выделенным на срок аренды;
- условия замены IP;
- доступность proxy endpoint напрямую без VPN;
- какие проверки репутации IP предлагает провайдер.

Ранее отдельно обсуждалась опция дополнительной проверки/более строгого отбора IP. Не считать старое описание этой опции актуальным — проверить текущий сайт/документацию.

### 2. Decodo Dedicated ISP — второй кандидат

Рассматривать, если предложение IPRoyal не подходит.

Перепроверить те же параметры: dedicated/static, ISP, SOCKS5, географию, цену, условия замены и прямую доступность endpoint без VPN.

### 3. Webshare Static Residential — резервный кандидат

Ранее рассматривался как более бюджетный вариант.

Shared IP для основной конфигурации проекта нежелателен. Если Webshare рассматривается всерьёз, отдельно проверить, есть ли подходящий **dedicated/static** вариант и как он отличается по цене и условиям.

## Как выбирать

На соответствующем этапе PLAN:

1. проверить актуальные официальные страницы/документацию всех трёх кандидатов;
2. не полагаться на цены и характеристики из старых заметок;
3. сравнить минимум: тип IP, dedicated/shared, static/rotating, SOCKS5, географию, срок аренды, цену, замену IP;
4. до длительной оплаты по возможности использовать короткий период/тест;
5. с выключенным системным VPN проверить доступность proxy endpoint;
6. после получения IP проверить его технические характеристики и репутацию несколькими независимыми источниками;
7. показать пользователю результаты и дождаться решения;
8. ничего не покупать автоматически.

## Граница проекта

Proxy используется как стабильный сетевой маршрут для изолированной среды Cage. Проект не предусматривает автоматическую ротацию IP/аккаунтов, подмену идентичности или обход блокировок/защит сервиса.
