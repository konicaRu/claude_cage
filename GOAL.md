# Claude Cage — цель проекта

## Цель

Настроить на Windows 10 стабильную изолированную среду Claude Cage, внутри которой работают:

- официальный Claude Desktop для Linux;
- Claude Code;
- браузер для авторизации и проверки Claude;
- Git и рабочие проекты.

Весь внешний трафик этой среды должен идти через один выделенный статический ISP/SOCKS5-прокси с хорошей репутацией. Системный VPN/Browsec на Windows для работы Claude не должен требоваться.

Проект предназначен для стабильного поддерживаемого сетевого окружения. Он не должен содержать механизмы обхода блокировок аккаунта, подмены идентичности или автоматического переключения аккаунтов/IP для обхода ограничений сервиса.

## Целевая архитектура

```text
Windows 10 host
│
├── обычные приложения Windows → обычная сеть
│
└── Claude Cage
    └── Linux guest (Ubuntu/Debian)
        ├── Claude Desktop
        ├── Claude Code
        ├── Browser
        ├── Git / project tools
        └── Mihomo/Cage network layer
             └── dedicated static ISP SOCKS5
                  └── Internet
```

## Критерии готовности

Проект готов, когда одновременно выполнены все пункты:

1. Claude Cage стабильно запускается на Windows 10.
2. Создан поддерживаемый Linux guest.
3. Внутри guest установлен официальный Claude Desktop.
4. Внутри guest установлен/доступен Claude Code.
5. Используется один выделенный статический ISP IP.
6. Перед использованием IP проверена его репутация; результаты проверки задокументированы без публикации секретов.
7. Cage настроен на SOCKS5-прокси.
8. Claude Desktop, Claude Code и браузер внутри Cage показывают один ожидаемый внешний IP.
9. Проверено отсутствие нежелательного прямого выхода при отключении/сбое прокси.
10. Проверены DNS и геолокация/часовой пояс сетевого окружения на разумную согласованность.
11. Авторизация Claude выполняется штатным способом.
12. Claude Desktop успешно отправляет и получает сообщения.
13. Claude Code успешно запускает тестовую сессию в тестовом Git-репозитории.
14. После перезагрузки Windows конфигурация сохраняется и снова работает.
15. Для работы Claude не требуется включать системный VPN/Browsec на Windows.
16. Пароли прокси, токены, cookies и другие секреты не находятся в Git.

## Не входит в первый этап

- Claude Cowork внутри Cage;
- Computer Use внутри Linux Claude Desktop;
- ротация IP;
- автоматическое переключение аккаунтов;
- обход ограничений или защит Anthropic;
- публикация секретов прокси в репозитории.
